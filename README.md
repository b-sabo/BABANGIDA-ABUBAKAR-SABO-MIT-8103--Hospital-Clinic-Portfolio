# MIT-8103--Hospital-Clinic-Portfolio
Hospital/Clinic System database portfolio for MIT 8103 Advanced Database Systems.

## Project Overview
This portfolio demonstrates database design and implementation for a Hospital/Clinic System. It explores relational database concepts, query optimisation, transaction processing, NoSQL data modelling, and cloud database deployment.

## Case Study
The system manages patient records, doctor information, and appointments. PostgreSQL provides the relational model, while MongoDB demonstrates a document-oriented approach to patient data.

## Activities

1. **Database Design and Modelling** — entities, relationships, keys, constraints, and normalisation.
2. **Query Processing and Optimisation** — SQL queries, execution plans, and indexing.
3. **Transactions and Concurrency** — transaction control using COMMIT and ROLLBACK, with concurrency concepts.
4. **NoSQL and Advanced Data Models** — MongoDB document modelling and querying.
5. **Distributed and Cloud Database Exercise** — cloud deployment and discussion of replication, sharding, availability, and consistency.
