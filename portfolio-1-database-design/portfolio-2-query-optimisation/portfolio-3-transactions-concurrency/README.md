# Activity 3: Transactions and Concurrency

## Aim
This activity demonstrates how database transactions protect data integrity in the Hospital/Clinic System.

## Database Used
PostgreSQL hosted on Neon.

## Transaction Tests
- **ROLLBACK:** Tests whether an uncommitted change can be cancelled.
- **COMMIT:** Tests whether a change can be saved permanently.
- **Concurrency and isolation:** Explores how transactions interact when multiple users access the database.

## Evidence
Screenshots of the transaction tests will be added to the `screenshots` folder after the project files have been created.

## Conclusion
Transactions help maintain reliable and consistent hospital records. ROLLBACK can cancel unwanted changes, while COMMIT saves intended changes.
