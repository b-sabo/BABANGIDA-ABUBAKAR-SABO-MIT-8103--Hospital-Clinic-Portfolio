# Activity 1: Database Design and Modelling

**Case Study:** Hospital/Clinic Management System

## Overview
This activity designs a relational database for managing patients, doctors, and appointments.

## Entities
- Patients
- Doctors
- Appointments

## Keys and Constraints
Primary keys uniquely identify records. Foreign keys connect appointments to patients and doctors. A unique constraint prevents duplicate bookings for the same patient, doctor, and appointment time.
